# 📊 AI Jobs Market Dashboard

An interactive data dashboard visualizing the AI/ML job market — 
built with HTML, CSS, and Chart.js. No backend required; runs entirely in the browser.

## 🔍 What It Shows
- Salary distributions across AI roles
- Top skills demanded by employers
- Job count by company size and location
- Remote vs on-site trends

## 🛠️ Tech Stack
HTML · CSS · JavaScript · Chart.js · D3.js

## 🚀 Live Demo
[View Dashboard](https://arshaimran.github.io/ai-job-dashboard)

## 💡 Use Case
Built as a tool for job seekers and career switchers to understand 
where the AI job market is heading and which skills have the highest ROI.
